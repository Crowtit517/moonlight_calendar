## 소개

달빛달력은 회원가입도, 설치도 필요 없는 개인용 캘린더 겸 가계부입니다.
남색과 보랏빛이 감도는 밤하늘 톤 위에, 하루짜리 일정부터 여러 날에 걸친 일정까지
막대 형태로 한눈에 볼 수 있도록 그렸습니다. 오른쪽에는 달을 눌러 고른 날짜의
일정과 지출을 함께 확인할 수 있는 패널이 붙어 있어요.

## ✨ 특징

| 기능 | 설명 |
|---|---|
| 📅 기간 일정 | 하루짜리부터 여러 날짜에 걸친 일정까지, 달력 위에 막대로 표시 |
| ⏰ 시간 지정 | 오전/오후 스크롤 선택 또는 "3:30 오후" 같은 직접 입력 모두 지원 |
| ✅ 할 일 모드 | 일정을 할 일로 등록하고 체크박스로 완료 표시 |
| 🎨 색상 커스터마이즈 | 5가지 프리셋 색상 + 원하는 색을 직접 고르는 컬러 피커 |
| 🪙 가계부 | 날짜별 지출 기록, 이번 달 합계와 연간 지출 그래프까지 자동 집계 |
| 📱 반응형 | 데스크톱은 사이드 패널, 모바일은 하단 시트로 자연스럽게 전환 |
| 💾 자동 저장 | 브라우저 로컬 저장소에 저장되어, 새로고침해도 기록이 남음 |

## ▶️ 사용 방법

1. 위 **"바로 사용해보기"** 버튼을 클릭합니다.
2. 원하는 날짜를 눌러 패널에서 일정을 추가합니다. 날짜 범위와 시간, 색상, 할 일 여부를 자유롭게 지정할 수 있어요.
3. 상단의 **🪙 가계부** 버튼으로 그날의 지출을 기록하고, 월별·연간 합계를 확인합니다.

## 🛠 기술 스택

- 순수 **HTML / CSS / JavaScript** (프레임워크·빌드 과정 없음)
- 파일 하나로 동작 → 다운로드 후 더블클릭만 해도 로컬에서 바로 실행 가능
- 데이터는 브라우저의 `localStorage`에 저장됩니다.
