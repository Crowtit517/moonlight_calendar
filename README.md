## 이걸 왜 만들었나

시작은 단순했습니다. "캘린더 형식의 앱을 하나 구상해서 만들어봐"라는 한 줄
요청이었어요. Claude에게 아티팩트로 만들어달라고 부탁했고, 며칠 동안 대화를
주고받으며 기능을 하나씩 붙여나갔습니다. 이 프로젝트가 재밌었던 건 단순히
"만들어졌다"가 아니라, 만드는 과정에서 곁가지 질문들에 답을 찾아가면서
결과적으로 "왜 지금 이 방식(웹 + 로컬 저장)으로 만들어졌는지"에 대한 이유가
뚜렷해졌다는 점입니다.

## 무엇이 들어있나 (기능 투어)

- 📅 **기간 일정** — 하루짜리부터 여러 날짜에 걸친 일정까지, 달력 위에 색깔 막대로 표시
- ⏰ **시간 지정** — 오전/오후 토글, 스크롤 선택, 직접 텍스트 입력까지 세 가지 방식이 서로 동기화
- ✅ **할 일 모드** — 일정을 체크박스로 완료 표시
- 🎨 **색상 커스터마이즈** — 프리셋 5종 + 컬러 피커
- 🪙 **가계부** — 날짜별 지출, 월 합계, 연간 막대그래프까지 자동 집계 (일정 패널과는 완전히 분리된 별도 창)
- 📱 **반응형** — 데스크톱은 사이드 패널, 모바일은 하단 시트

## 만들어진 과정 (제작 일지)

처음부터 이 모습은 아니었습니다. 대화를 거치며 이렇게 다듬어졌어요.

1. **가계부 기능 추가** — 날짜별 지출 입력, 월별 합계, 연간 누적 막대그래프 기능을 처음 구현
2. **가계부 분리 + 기간 일정 + 색상 지정** — 가계부를 완전히 별도 모달 창으로 분리하고, 일정은 시작일~종료일 범위와 원하는 색상을 지정해 막대로 표시하도록 개선
3. **미니 캘린더 도입** — 브라우저 기본 날짜 입력창 대신, 직접 만든 미니 달력으로 일정 범위와 가계부 날짜를 클릭해서 선택하도록 교체
4. **시간 선택 완성** — 오전/오후 토글, 시·분 스크롤 선택, "3:30 오후" 같은 직접 입력까지 세 가지 방식이 서로 실시간으로 동기화되도록 구현
5. **exe 전환 시 취약점 분석** — 실제로 만들진 않았지만, 이 웹앱을 exe로 바꿨을 때 생기는 보안 리스크(코드 서명, 샌드박스 이탈, 공급망 공격 등)를 짚어본 흥미로운 사고실험

## ▶️ 사용 방법

1. 위 **"바로 사용해보기"** 버튼을 클릭해 페이지를 엽니다.
2. 달력에서 원하는 날짜를 클릭하면 오른쪽(모바일은 하단) 패널이 그 날짜 기준으로 바뀝니다.
3. 패널의 입력창에 내용을 적고, 필요하면 날짜 범위·시간·색상·할 일 여부를 지정한 뒤 **"담아두기"**를 누릅니다.
4. 상단의 **🪙 가계부** 버튼을 눌러 그날의 지출 금액과 메모를 추가하고, 월별·연간 합계를 확인합니다.
5. 등록한 일정이나 지출은 목록의 ✕ 버튼으로 언제든 삭제할 수 있습니다.

## 🛠 기술적으로 흥미로웠던 점

- 겹치는 기간 일정을 자동으로 다른 줄(레인)에 배치하는 간단한 구간 스케줄링 알고리즘
- `localStorage`와 원격 DB 중 사용 가능한 쪽으로 자동 전환되는 저장 추상화 (원래 아티팩트 버전의 흔적)
- 순수 HTML/CSS/JavaScript, 프레임워크·빌드 과정 없이 파일 하나로 동작
