# 🌙 달빛달력 (Moonlight Calendar)

> 하루에서 며칠까지, 원하는 색으로 일정을 담아두는 다크 테마 캘린더입니다.
> 일정 관리만이 아니라 그날그날의 지출까지 한 곳에 기록할 수 있게 만들었습니다.

## 소개

세상에는 이미 좋은 캘린더 앱이 많습니다. 그런데 정작 "오늘 뭐 했지, 얼마 썼지"를
동시에 확인하려면 캘린더 앱과 가계부 앱을 번갈아 켜야 했어요. 달빛달력은 그 두 가지를
한 화면 안에 욱여넣어 보자는 생각에서 시작된 개인용 프로젝트입니다.

회원가입도, 설치도, 로그인도 없습니다. 링크 하나 열면 바로 이번 달 달력이 뜨고,
날짜를 누르면 그날의 일정과 지출이 오른쪽 패널에 함께 나타납니다. 배경에는
남색과 짙은 보랏빛이 은은하게 번지는 그라디언트를 깔고, 제목은 세리프 계열의
'Gowun Batang' 폰트로 잡아서 딱딱한 툴이 아니라 밤에 조용히 펼쳐보는 다이어리 같은
느낌을 내려고 했습니다.

## 🖥️ 화면 구성

화면은 크게 세 영역으로 나뉩니다.

- **달력 그리드 (왼쪽/전체)** — 이번 달의 날짜가 7×6 격자로 펼쳐집니다. 일요일은 붉은빛,
  토요일은 푸른빛으로 살짝 구분해두었고, 오늘 날짜에는 달 모양의 하이라이트가 붙습니다.
- **일정 막대 (달력 위)** — 하루짜리 일정은 점으로, 여러 날에 걸친 일정은 시작일부터
  종료일까지 이어지는 색깔 막대로 표시됩니다. 겹치는 일정은 자동으로 다른 줄(레인)에
  배치되어 최대 3줄까지 겹쳐 보여줍니다.
- **일정/가계부 패널 (오른쪽, 모바일에서는 하단 시트)** — 날짜를 클릭하면 그날 등록된
  일정 목록과 새 일정을 추가하는 폼이 나타납니다. 상단의 "🪙 가계부" 버튼을 누르면
  별도의 모달 창이 뜨며 지출 기록, 월별 합계, 연간 지출 그래프를 확인할 수 있습니다.

## ✨ 자세히 보는 기능

### 📅 날짜 범위가 있는 일정

일정을 추가할 때 "날짜 선택" 버튼을 누르면 미니 달력이 펼쳐집니다. 하루를 클릭하면
시작일, 다시 다른 날을 클릭하면 종료일이 지정되는 방식이라 여행이나 프로젝트처럼
며칠씩 이어지는 일정도 손쉽게 등록할 수 있습니다. 등록된 일정은 달력 위에
막대 형태로 걸쳐서 보이기 때문에, 굳이 하루하루 눌러보지 않아도 "이번 주에 뭐가
겹쳐 있는지"를 한눈에 파악할 수 있어요.

### ⏰ 시간 지정 — 스크롤과 직접 입력 모두 지원

시간이 있는 일정(회의, 약속 등)은 "⏰ 시간 없음 (종일)" 버튼을 눌러 시간을 지정할 수
있습니다. 오전/오후 토글과 시·분을 스크롤로 고르는 방식, 그리고 "3:30 오후"처럼
텍스트를 직접 타이핑하는 방식이 서로 실시간으로 동기화되어 있어서 편한 쪽으로
입력하면 됩니다.

### ✅ 할 일 모드

같은 입력 폼에서 "할 일로" 체크박스만 켜면 그 일정은 캘린더 막대뿐 아니라 패널
목록에도 체크박스가 달린 할 일로 등록됩니다. 완료 표시를 하면 제목에 취소선이
그이고, 막대도 반투명하게 흐려져서 "끝난 일"이라는 게 캘린더 위에서도 바로 드러납니다.

### 🎨 색상 커스터마이즈

로즈·민트·앰버·바이올렛·문라이트 5가지 프리셋 색상 중 하나를 고르거나, 원형
컬러 피커로 원하는 색을 직접 지정할 수 있습니다. 색상은 일정 막대와 패널의 점
색상에 그대로 반영되어, 카테고리별로(예: 업무는 파랑, 개인 일정은 분홍) 색을
구분해두면 달력만 봐도 무슨 일정인지 짐작할 수 있습니다.

### 🪙 가계부

상단의 "🪙 가계부" 버튼을 누르면 별도의 모달 창이 뜹니다. 날짜를 고르고 금액과
메모를 입력하면 지출이 기록되고, 아래에는 자동으로 세 가지 숫자가 집계됩니다.

- 그날 하루의 지출 합계
- 이번 달 전체 지출 합계
- 올해 1월부터 12월까지 월별 지출을 막대그래프로 보여주는 연간 요약 (막대를 클릭하면 해당 월로 바로 이동)

캘린더 위에서도 지출이 있는 날짜 칸 아래에 "-12,000원" 처럼 그날 쓴 금액이 작게
표시되기 때문에, 달력을 넘겨보는 것만으로도 "이 주에 돈을 좀 썼구나"를 알아챌 수
있습니다.

### 📱 반응형 레이아웃

데스크톱 화면(780px 이상)에서는 일정/가계부 패널이 달력 오른쪽에 고정되어 있고,
스크롤해도 항상 보이는 sticky 패널로 동작합니다. 화면이 좁아지면(모바일) 패널이
화면 하단에서 올라오는 바텀시트 형태로 바뀌어서, 손가락으로 스와이프하듯 자연스럽게
열고 닫을 수 있습니다.

### 💾 자동 저장 & 기기 간 동기화 대비

모든 일정과 지출 데이터는 브라우저의 `localStorage`에 저장됩니다. 앱을 새로고침하거나
탭을 닫았다가 다시 열어도 기록이 그대로 남아 있어요. 코드 내부적으로는 저장소를
`localStorage`와 원격 데이터베이스(Claude의 `db` 런타임 기능) 중 사용 가능한 쪽으로
자동 전환하도록 짜여 있어서, 추후 기기 간 동기화가 필요해지면 큰 구조 변경 없이도
확장할 수 있는 여지를 남겨두었습니다. 상단의 작은 알약 모양 표시(sync pill)가 현재
어느 저장 모드로 동작 중인지 알려줍니다.

## 📖 만들어진 과정 (제작 일지)

처음부터 이 모습은 아니었습니다. 대화를 거치며 이렇게 다듬어졌어요.

1. **가계부 기능 추가** — 날짜별 지출 입력, 월별 합계, 연간 누적 막대그래프 기능을 처음 구현
2. **가계부 분리 + 기간 일정 + 색상 지정** — 가계부를 완전히 별도 모달 창으로 분리하고, 일정은 시작일~종료일 범위와 원하는 색상을 지정해 막대로 표시하도록 개선
3. **미니 캘린더 도입** — 브라우저 기본 날짜 입력창 대신, 직접 만든 미니 달력으로 일정 범위와 가계부 날짜를 클릭해서 선택하도록 교체
4. **시간 선택 완성** — 오전/오후 토글, 시·분 스크롤 선택, "3:30 오후" 같은 직접 입력까지 세 가지 방식이 서로 실시간으로 동기화되도록 구현
5. **exe 전환 시 취약점 분석** — 실제로 만들진 않았지만, 이 웹앱을 exe로 바꿨을 때 생기는 보안 리스크(코드 서명, 샌드박스 이탈, 공급망 공격 등)를 짚어본 흥미로운 사고실험

## ▶️ 사용 방법

1. 위 **"바로 사용해보기"** 버튼을 클릭해 페이지를 엽니다.
2. 달력에서 원하는 날짜를 클릭하면 오른쪽(모바일은 하단) 패널이 그 날짜 기준으로 바뀝니다.
3. 패널의 입력창에 내용을 적고, 필요하면 날짜 범위·시간·색상·할 일 여부를 지정한 뒤 **"담아두기"**를 누릅니다.
4. 상단의 **🪙 가계부** 버튼을 눌러 그날의 지출 금액과 메모를 추가하고, 월별·연간 합계를 확인합니다.
5. 등록한 일정이나 지출은 목록의 ✕ 버튼으로 언제든 삭제할 수 있습니다.

## 🛠 기술 스택 & 구현 메모

- 순수 **HTML / CSS / JavaScript**로만 작성했습니다. 별도의 프레임워크나 빌드 과정이 없어서, 파일 하나만 다운로드해도 더블클릭으로 바로 실행됩니다.
- 여러 날에 걸친 일정이 겹칠 때 자동으로 줄(레인)을 나눠 배치하는 간단한 구간 스케줄링 알고리즘을 직접 구현했습니다.
- 폰트는 구글 폰트의 'Gowun Batang'(제목)과 'Gowun Dodum'(본문)을 사용해 손글씨 느낌이 살짝 도는 다이어리 톤을 냈습니다.
- 데이터 저장은 `localStorage`를 기본으로 하되, 원격 저장소가 감지되면 그쪽으로 자동 전환되는 추상화 레이어를 두었습니다.
- 다크 모드 전용 색상 시스템(CSS 커스텀 프로퍼티)으로 배경·표면·글자·강조색을 일관되게 관리합니다.
